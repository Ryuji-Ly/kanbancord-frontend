---
title: Choose which columns count as done, and task suggestions in Discord
date: 2026-11-15
---
- **Choosing a task in Discord commands suggests the board's tasks again.** Since 24 October, the `task` option of `/task` and `/comment` showed "No options match your search", even when empty. Typing the task's full name still worked.
- **Choose which columns count as done.** Tasks in a done column get no due-date reminders and count as done in a label's progress, and ticked items you import go there. Until now that was always the last column, which did not work for boards with a column after Done, or with both Done and Won't do. Use **Counts as done** in a column's ⋯ menu, or `/column done` in Discord. Until you mark one, the last column still counts as done.
- **Comments on the roadmap.** Anyone can read the comments on a roadmap issue, and anyone signed in can add one, under their Discord name. Whoever reported the issue, and anyone who commented on it, gets a direct message when someone answers, with a link straight to it.
